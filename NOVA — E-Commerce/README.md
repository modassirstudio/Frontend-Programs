# NOVA — E-Commerce Website 🛍️

A modern, responsive e-commerce website built using **HTML, CSS, and JavaScript**. NOVA features a clean and minimal design with product browsing, category filtering, search functionality, and an interactive shopping cart.

## 🌐 Live Demo

Add your GitHub Pages link here after deployment.

## 📸 Features

- Modern and minimal user interface
- Fully responsive design (desktop, tablet, and mobile)
- Product listing with sample products
- Product category filtering
- Search products by name or category
- Interactive shopping cart
- Add and remove products from cart
- Increase and decrease product quantities
- Automatic subtotal calculation
- Cart data persistence using LocalStorage
- Newsletter subscription interaction
- Smooth scrolling and interactive UI elements

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layouts, animations, and responsiveness
- **JavaScript (Vanilla JS)** — Functionality and interactivity
- **LocalStorage** — Saving shopping cart data in the browser

## 💻 Website Functionality

### Product Browsing
Browse different products across Home, Accessories, and Wellness categories.

### Search and Filtering
Search for products and filter them by category.

### Shopping Cart
Add products to your cart, update quantities, remove items, and view the automatically calculated subtotal.

### LocalStorage
Shopping cart information is saved in your browser, so it remains available after refreshing the page.

The website is designed to work across:

## ⚠️ Current Limitations

This project is currently a frontend demonstration.

- Checkout is not connected to a payment gateway.
- Products are sample data stored in JavaScript.
- There is no backend database.
- User authentication is not implemented.
- Newsletter subscriptions are not sent to a real mailing service.
