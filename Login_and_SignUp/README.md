# Responsive Login & Sign Up Page

A modern and responsive **Login & Sign Up authentication UI** built using **HTML, CSS, and JavaScript**.

This project is created as a frontend mini project to practice responsive web design, form validation, JavaScript DOM manipulation, and multi-page navigation.

## 🔑 Login Page

The login page includes:

* Email input
* Password input
* Show/Hide password
* Remember me checkbox
* Forgot password link
* Form validation
* Sign Up navigation

## 📝 Sign Up Page

The Sign Up page includes:

* Full name input
* Email input
* Password input
* Confirm password input
* Show/Hide password
* Terms & Conditions checkbox
* Form validation
* Password matching validation
* Login navigation

## 📱 Responsive Design

The interface adapts to different screen sizes:

* Desktop
* Laptop
* Tablet
* Mobile

CSS media queries are used to make the layout responsive.

## ⚠️ Note

This is a **frontend-only project**.

It does not connect to a database or backend authentication system. The login and registration forms currently demonstrate frontend validation and UI interactions only.

Built as part of my frontend development learning journey.
